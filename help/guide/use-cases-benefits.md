# Adobe Real-Time CDP Collaboration的主要優點和使用案例

{{limited-availability-release-note}}

Adobe Real-Time CDP Collaboration提供基本功能，讓您能夠有效地探索、啟用和衡量對象，確保您的行銷策略保持健全且以資料為導向，而且一切都在以隱私權為中心的空間中。

<!-- This graphic needs to be updated, it's incorrectly using "brands". -->

![Real-Time CDP Collaboration的優點和使用案例](/help/assets/benefits-use-cases/discover-activate-measure.png)

## 探索 {#discover}

使用控制面板和報表來探索共同作業的對象。 作為使用Collaboration的廣告商，存取並瞭解對象重疊，以從眾多發佈商中解鎖重新目標定位、隱藏和潛在潛在的發展機會。

## 啟動 {#activate}

發佈者可使用自助式[設計](/help/guide/destinations/experience-platform.md)或雲端資料倉儲(例如Amazon S3或Snowflake)，安全地為Experience Platform啟用對象，以用於行銷活動。

## 衡量 {#measure}

結合併探索來自各種來源的已知客戶參與，例如網頁印象等。 在簡化且可自訂的報表中檢視促銷活動績效。
