# Adobe Real-Time CDP Collaboration的主要優點和使用案例

{{limited-availability-release-note}}

Adobe Real-Time CDP Collaboration提供基本功能，讓您能有效探索、啟用和測量對象，確保您的行銷策略穩健且以資料為導向，這一切都放在隱私權優先的空間。

![Real-Time CDP Collaboration的優點和使用案例](/help/assets/benefits-use-cases/discover-activate-measure.png)

## 探索 {#discover}

使用儀表板和報表來探索品牌對發佈者共同作業的受眾。
作為使用Real-Time CDP Collaboration的廣告商，存取並瞭解對象重疊，以從眾多發佈商中解鎖重新目標定位、隱藏和潛在潛在的發展機會。

## 啟動 {#activate}

發佈者可以安全地從Adobe Real-Time CDP、雲端資料倉儲（未來版本）和其他系統（未來版本）啟用對象，以利行銷活動。
在未來版本中，請與選取的身分識別合作夥伴合作，運用真實身分，並使用身分交叉通路來擴大觸及率。

## 衡量 {#measure}

結合併探索來自各種來源的已知客戶參與，例如網頁印象等。
在簡化且可自訂的報表中檢視促銷活動績效。
