# Real-Time CDP Collaboration [!DNL Starter]中的信用使用量和消耗量

本檔案提供當您以受邀使用者身分加入Adobe Real-Time CDP Collaboration [!DNL Starter]時如何使用積分的詳細資訊。 瞭解更多關於誰應負責信用使用情況，以及存取和管理的重要考量。

如需Collaboration [!DNL Starter]的一般總覽，請閱讀[Real-Time CDP Collaboration [!DNL Starter] 總覽](../overview/starter-overview.md)。

## 信用使用方式的運作方式 {#credit-usage}

接受邀請後，邀請您的組織會涵蓋您活動的所有信用使用。 積分一律會從邀請者的帳戶中扣除，不會向您自己的帳戶收費。

## 管理存取權和期望 {#manage-access-and-expectations}

Collaboration **不**&#x200B;會自動強制使用信用或可用性。 這表示:

* 身為受邀使用者，您必須直接與邀請您討論信用使用的組織或合作夥伴協調。
* 您的邀請組織負責決定：
   * 何時可以存取及使用Collaboration功能
   * 關於信用消耗的限制、限制或治理有哪些

>[!IMPORTANT]
>
> Adobe不會管理或仲裁組織之間的信用共用合約。 所有使用預期都應直接在您和邀請合作夥伴之間商定。

如需如何在組織之間配置積分的詳細資訊，請參閱[連線設定指南](../connect/establishing-connections.md)中的[積分分割設定](../connect/establishing-connections.md#credit-split)區段。

若要進一步瞭解哪些活動耗用信用及如何追蹤或管理信用使用情況，請參閱[追蹤您的信用耗用活動](./my-activity.md)。
