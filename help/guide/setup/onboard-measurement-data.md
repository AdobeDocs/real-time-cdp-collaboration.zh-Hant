# 新增及管理測量資料

{{limited-availability-release-note}}

本檔案概述將行銷活動測量資料新增至Adobe Real-Time CDP Collaboration的步驟。 發佈者可與Adobe團隊合作，上傳行銷活動測量資料。 上傳並處理資料之後，發佈者和廣告商都能檢視廣泛的[行銷活動測量報告](/help/guide/collaborate/measure.md)。
