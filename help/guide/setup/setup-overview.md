# 設定區段概觀

{{limited-availability-release-note}}

Real-Time CDP Collaboration中的設定區段是您開始使用產品時新增公司相關資訊的首選位置。 此畫面也是返回，用於管理各種資源（例如對象詳細資訊或比對索引鍵）的地方。

使用設定區段中的功能可以：

* 在Adobe Real-Time CDP Collaboration中[加入並管理組織的各個層面](/help/guide/setup/onboard-organization.md)
* [匯入和管理對象](/help/guide/setup/onboard-audiences.md)
* [檢視資料連線](/help/guide/setup/manage-data-connection.md)
* [追蹤您的積分活動](/help/guide/setup/my-activity.md)
* 您的廣告行銷活動的[內建測量資料](/help/guide/setup/onboard-measurement-data.md)
