# Collaboration使用案例

{{limited-availability-release-note}}

Adobe Real-Time CDP Collaboration可與廣告商及發佈商共同作業，開啟受眾探索、啟用和測量的新商機。 這些連線可運用共用資料，同時維護隱私權和安全性，進而增強行銷策略。

Collaboration提供您與其他共同作業人員建立連線時的三個主要使用案例：探索、啟用和測量。 每個使用案例都提供獨特的好處和功能，以增強您的行銷工作。 當您與共同作業人員建立專案[&#128279;](../collaborate/manage-projects.md#project-use-cases)以啟動行銷活動時，會選取這些使用案例，並將決定該專案中可用的功能。

## 探索 {#discover}

![探索對象深入分析儀表板模組。](/help/assets/use-cases/discover.png)

在您的專案中運用&#x200B;**[!UICONTROL 對象深入分析]**&#x200B;儀表板，探索行銷活動的目標對象。 將insight轉換為對象與共同作業人員之間的重疊百分比和重疊身分數目。 這可協助您識別行銷活動的潛在新對象。 若要進一步瞭解探索使用案例的功能，請參閱[探索](../collaborate/discover.md)指南。

## 啟動 {#activate}

![啟用對象儀表板模組。](/help/assets/use-cases/activate.png)

共同作業人員可使用自助式[目的地](/help/guide/destinations/experience-platform.md)或雲端資料倉儲（例如[!DNL Amazon S3]或[!DNL Snowflake]），在Experience Platform中啟用對象，以用於行銷活動。 若要進一步瞭解啟用對象，請參閱[啟用](../collaborate/activate.md)指南。

>[!NOTE]
>
> 若要設定Cloud Data Warehouse目的地，請聯絡您的Adobe代表。

## 衡量 {#measure}

結合併探索來自各種來源的已知客戶參與，例如網頁印象等。 在簡化且可自訂的報表中檢視促銷活動績效。
