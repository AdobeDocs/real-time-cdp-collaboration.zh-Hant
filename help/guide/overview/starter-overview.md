# Adobe Real-Time CDP Collaboration入門概述

有了Adobe Real-Time CDP Collaboration Starter，您可以加入授權合作夥伴，與它合作開展以隱私權為中心的資料共同作業，而不需要您自己的Collaboration授權。

您的授權合作夥伴邀請您前往Collaboration，並使用其成果在廣告商對發佈商及品牌對品牌模式中，為您的共同工作流程提供資金。 若要進一步瞭解這些模式及其運作方式，請閱讀[共同作業模式](./collaboration-patterns.md)和[端對端工作流程](./end-to-end-workflow.md)指南。

身為受邀入門客戶，您可以：

* 在入門帳戶中載入及管理共同作業資料
* 用於聯合專案的Source和維護對象
* 深入瞭解與合作夥伴的對象重疊，以支援有效的目標定位和促銷活動測量
* 啟用對象並與您的合作夥伴分享，以進行聯合行銷活動啟用和參與

## 先決條件 {#prerequisites}

若要開始使用Collaboration Starter，請確認您的組織和授權合作夥伴位於相同地區。 您必須受到擁有Real-Time CDP Prime、Ultimate或Collaboration授權的合作夥伴的邀請。

若要啟動邀請，請提供下列資訊給您的授權合作夥伴：

* 連絡人姓名
* 聯絡人電子郵件
* 公司
* 角色（廣告商/發佈商）：廣告商
* 行業
* 管理員名稱（若與聯絡人名稱不同）
* 管理員連絡人電子郵件（若與連絡人電子郵件不同）

收到並接受邀請後，貴組織必須檢閱並簽署Adobe的免費銷售訂單，才能存取Collaboration Starter。
