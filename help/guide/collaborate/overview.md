# 共同作業概觀

{{limited-availability-release-note}}

與共同作業人員建立連線後，您可以建立專案以開始共同作業。 專案是Real-Time CDP Collaboration的核心，可讓您執行對象重疊計算、探索相關對象、在您的廣告平台啟用對象，以及測量行銷活動績效。 專案中可用的功能取決於連線設定期間選取的使用案例。

## 專案使用案例 {#project-use-cases}

專案概述會顯示連線設定期間選取的使用案例。 這些使用案例定義了專案中可用的功能。 使用案例包括：

| 使用案例 | 專案區段 |
| --- | --- |
| 行銷活動衡量 | 此使用案例授予[量值](/help/guide/collaborate/measure.md)區段和所有可用功能的存取權。 |
| 客群探索 | 此使用案例授予[探索](/help/guide/collaborate/discover.md)區段和所有可用功能的存取權。 |
| Audience Activation | 此使用案例授予[啟用](/help/guide/collaborate/activate.md)區段和所有可用功能的存取權。 |

## 與廣告平台合作 {#collaborating-with-advertising-platforms}

與廣告平台的合作將因特定平台及其功能而異。 目前，Real-Time CDP Collaboration中唯一可用的廣告平台是[!DNL Amazon Marketing Cloud] ([!DNL AMC])。 如需與[!DNL AMC]共同作業的詳細資訊，請閱讀[[!DNL Amazon Marketing Cloud]](/help/guide/collaborate/advertising-platforms/amc.md)指南。
